# **Projeto Cinema**

**Requisitos Funcionais:**
* **RF01:** O sistema deve listar o catálogo de filmes em cartaz, suas sessões e horários.
* **RF02:** O sistema deve exibir a quantidade de ingressos disponíveis por sessão.
* **RF03:** O sistema deve permitir a compra de um ingresso, deduzindo a vaga do banco de dados.
